# 全球車訊日報（學生作業示範版）

使用 HTML、CSS、JavaScript 製作的響應式汽機車新聞主題網站。

## 功能
- 大型頭條、黑紅性能車風格
- 新聞搜尋、品牌與類別篩選
- 台灣交通法規官方入口
- 焦點新聞列表（非真實熱門統計）
- 汽機車規格比較介面（示範數據）
- 手機版響應式選單

## 執行
直接開啟 `index.html`，或將整個資料夾上傳至 GitHub 儲存庫，啟用 GitHub Pages（Deploy from a branch，main，/root）。

## 重要說明
這是課堂作業展示版，不會自動更新新聞。文章是教學示範主題，並非即時新聞；車輛規格是明確標註的示範值。Unsplash 圖片是主題示意照片，不代表特定新聞車型。若要正式發布新聞，須改為已核對的新聞資料與授權圖片。
